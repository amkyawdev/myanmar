# Myanmar AI Skill

Myanmar AI Assistant သည် Groq API ကို အသုံးပြု၍ မြန်မာ ဘာသာစကားကို အဆင့်မြင့်စွာ နားလည်ပြီး ဖြေကြားပေးသည့် AI အကူအညီ ပရိုဂရမ်ဖြစ်ပါသည်။

## အဓိက လုပ်ဆောင်ချက်များ

### Real-time Chat
- Groq API ကို အသုံးပြု၍ အမြန်တုံ့ပြန်မှု
- စကားလုံးချင်းဆီ တစ်ခြင်းတစ်ခြင်း ပြန်ပေးမှု
- မြန်မာ ဘာသာစကားကို အဆင့်မြင့်စွာ နားလည်ပြီး ဖြေကြားပေးမှု

### Streaming Response
- API streaming ကို အသုံးပြု၍ အမြန်တုံ့ပြန်မှု
- Real-time status updates
- Smooth animations

### PWA Support
- မိုဘိုင်းလ်တွင် အပ်ပလီကေးရှင်းအဖြစ် ထည့်သွင်းအသုံးပြုနိုင်သည်
- Offline support
- Push notifications

## အသုံးပြုနည်း

1. Home page မှ "စတင်ပြောဆိုမည်" ခလုတ်ကို နှိပ်ပါ
2. Chat page သို့ သွားပါ
3. သင်၏မေးခွန်းကို ရေးပြီး send ခလုတ်ကို နှိပ်ပါ
4. AI အကူအညီမှ ဖြေကြားချက်များ ရယူပါ

## အကျိုးအlabels များ

- အမြန်တုံ့ပြန်မှု - Groq API ၏ အမြန်ဆုံး LLM
- မြန်မာ ဘာသာစကား - အဆင့်မြင့် Burmese language support
- PWA - မိုဘိုင်းလ်တွင် အပ်ပလီကေးရှင်းအဖြစ် အသုံးပြုနိုင်မှု
- Offline Support - အင်တာနက်မဲ့အခါ အသုံးပြုနိုင်မှု
