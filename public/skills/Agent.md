# Agent Mode

Agent mode သည် အဆင့်မြင့် AI agent အဖြစ် လုပ်ဆောင်ပြီး အမျိုးမျိုးသော လုပ်ဆောင်ချက်များ ကိုယ်တိုင် ဆုံးဖြတ်နိုင်သည့် လုပ်ဆောင်ချက်ဖြစ်ပါသည်။

## အသုံးပြုနည်း

1. သင်၏ရည်မှန်းချက်ကို ရေးပါ
2. Agent mode ကို ရွေးချယ်ပါ
3. AI agent သည် အဆင့်တစ်ဆင့်ပြီး အဆင့်တစ်ဆင့် လုပ်ဆောင်ပြီး ရည်မှန်းချက်ကို ပြည့်ဝစေပါသည်

## အကျိုးအbenefit များ

- ရည်မှန်းချက်ကို အလိုအလျှောက် ပြည့်ဝစေသည်
- အမျိုးမျိုးသော လုပ်ဆောင်ချက်များ ကိုယ်တိုင် ဆုံးဖြတ်သည်
- အခြေအနေအလျှောက် လုပ်ဆောင်သည်
