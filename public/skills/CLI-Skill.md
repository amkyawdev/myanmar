# CLI Skill

CLI Skill သည် command line interface မှတစ်ဆင့် အမျိုးမျိုးသော လုပ်ဆောင်ချက်များ ပြုလုပ်နိုင်သည့် လုပ်ဆောင်ချက်ဖြစ်ပါသည်။

## အသုံးပြုနည်း

1. CLI command များကို ရေးပါ
2. Execute ခလုတ်ကို နှိပ်ပါ
3. ရလဒ်များ ရယူပါ

## အကျိုးအbenefit များ

- အမျိုးမျိုးသော command များ အသုံးပြုနိုင်သည်
- အလွယ်တကူ လုပ်ဆောင်နိုင်သည်
- အမြန်တုံ့ပြန်မှု
